# Peach Widgets 官网

Peach 官方独立站点源码（静态 HTML + CSS）。内容由旧作品集域名 `zyjdesign.xyz` 上的 Peach 页面逐字迁移而来。

## 页面

- `/` 首页
- `/privacy` 隐私政策
- `/support` 支持

## 托管

- GitHub：仅作为源码仓库。
- 腾讯云 EdgeOne Pages（项目 `peach-widgets`）：正式生产托管。
- 自定义域名：`https://peachwidgets.site`（canonical），`www.peachwidgets.site` 301 到主域名。
- 不启用 GitHub Pages。
